# Tokens que a passada de prosa NUNCA substitui e que o gate de citação
# pendurada NUNCA cobra. A proteção é TOTAL e corta antes de qualquer oráculo:
# cega as duas ferramentas ao mesmo tempo. Por isso só entra aqui token que NÃO
# É CITAÇÃO DE IDENTIFICADOR renomeado — nome de coluna, chave de exemplo,
# placeholder de sintaxe, campo de corpus, palavra de prosa.
#
# O que era o grosso desta lista SAIU quando o renamecite ganhou o oráculo da
# declaração viva (collectDeclarations): `Nome`, `Colunas`, `Duracao`,
# `BytesRetidos` e `escreveAtomico` são identificadores VIVOS de pacotes que o
# ciclo ainda não mapeou, e agora quem os segura é a árvore — a ferramenta os
# reporta como `pulado ... ainda declarado <pacote>.<nome>` e o gate os aceita
# como declaração viva. Proteger identificador vivo era esconder do gate as
# citações penduradas do MESMO nome dentro do pacote que o perdeu.
#
# Cada linha abaixo entrou porque uma rodada de verdade a aplicou onde não era
# citação, e a linha foi revertida à mão.
#
#   - placeholder e chave de exemplo: `campo`, `valor`, `tipo`, `chave`
#     (`--param <tipo>:<valor>`, `[tipo][payload]`, `"campo": null`);
#   - nome de campo do CORPUS e da tabela virtual, que é dado em disco:
#     `campos`, `texto`, `hora`;
#   - nome de campo de EXEMPLO em bloco ```go de documento: `Data`, de
#     `RecordBuffer{Data []byte}` na spec (§21), que não é `buildinfo.Data`;
#   - identificador de pacote que o ciclo não mapeou e que o oráculo não
#     alcança: `emite` (do executor) e `seg` (variável local) são minúsculos, e
#     o gate nem os procura;
#   - VERBO PT-BR que abre frase de godoc e é homônimo de método renomeado:
#     `Existe`. É o único caso que o oráculo NÃO resolve, porque
#     `Presenca.Existe` virou `Presence.Exists` e o nome não existe mais em
#     lugar nenhum — sem a proteção, "Existe como sentinela próprio porque…"
#     (internal/types/types.go:66,84,144) e os dois blocos ```go de
#     planning/colunas-congeladas-e-ttl-condicional-plano.md:793,1419 viram
#     `Exists`. O idioma "Existe porque…" abre godoc em mais de vinte arquivos
#     deste repositório. `Nunca` é o segundo caso, e pela mesma mecânica: a
#     constante `rowindex.Nunca` virou `Never`, e o ADVÉRBIO que abre frase
#     ("Nunca cresce na leitura", internal/storage/rowindex/dense32.go:34;
#     "Nunca reordene", "Nunca aloca quando a chave já existe", nos dois
#     planos) não é citação nenhuma. As citações verdadeiras da constante já
#     estão em inglês — o godoc de schedule.go:140,186 e as formas
#     qualificadas `rowindex.Nunca` —, e o que a proteção segura daqui para a
#     frente é só o advérbio. `Vazio` é o terceiro: `Cadeias.Vazio` e
#     `Escritor.Vazio` viraram `IsEmpty`, mas em
#     planning/colunas-congeladas-e-ttl-condicional-plano.md:955 o `Vazio` que
#     abre frase é o ADJETIVO que descreve o campo `When` sem conteúdo
#     ("Vazio marca a regra de FUNDO"), e não método nenhum. As oito citações
#     verdadeiras deste ciclo já saíram como `IsEmpty`. `Com` é o quarto, e o
#     único em que o CONTEXTO é que engana: `FamiliaContador.Com` virou
#     `With`, e em planning/fase7-driver-jdbc.md:102 o `Com` que abre frase é
#     a PREPOSIÇÃO ("Com o descritor eles deixam de ser iguais"). O gate a lê
#     como citação porque conta as crases a partir do início da LINHA, e a
#     crase que fecha ali abriu na linha anterior — a contagem dá ímpar e ele
#     conclui "dentro de crase". As citações reais de `Com` já saíram como
#     `With` na passada de internal/metrics.
#   - NOME DE ARQUIVO EM DISCO cuja base é homônima de identificador
#     renomeado: `vazio.bin`, o tempdir de
#     internal/storage/mmap/region_test.go:337. O ponto o faz passar por
#     endereço qualificado, e o tipo `vazio` do segindex (union.go) virou
#     `emptyIter` — sem a proteção o arquivo de teste passa a se chamar
#     `emptyIter.bin`, que não é nome de arquivo que ninguém escreveria.
#   - endereço QUALIFICADO homônimo cujo dono é OUTRO tipo, vivo e não
#     mapeado, que o oráculo da declaração viva não alcança porque só olha o
#     token nu: `Fonte.Estado` é o campo de internal/metakafka.Fonte
#     (registry.go:80), e o `Fonte` → `Source` do segindex é outro tipo, sem
#     campo `Estado` (sealed.go:28); `Escritor.Apenda` é a INTERFACE FICTÍCIA
#     do fixture do próprio ferramental — dado de teste em
#     scripts/renametools/inventory_test.go:30 e o exemplo dos comentários de
#     scripts/ifacerename/rewrite.go:196 e scripts/renametools/groups.go:108,
#     onde o `Escritor` nu da linha vizinha fica e trocar só a metade
#     qualificada quebraria o teste e a frase. `Arquivo.Apenda` é o mesmo
#     fixture (inventory_test.go:39), e a linha seguinte cita
#     `Arquivo.Apenda.chave`, que o mapeamento não alcança;
#   - VALOR DE RÓTULO de métrica homônimo de campo privado: `selado`, do
#     `estado` de `nishidb_index_segmentos` (internal/metrics/names.go:393,
#     internal/storage/store.go:576,609 e mais treze citações em README,
#     docs e planning). O campo `Arquivo.selado` do spill virou
#     `Run.sealed`, e sem a proteção o valor do rótulo mudaria em crase pela
#     metade — `corrente`, `pendente` e `fora` ficariam —, que é contrato de
#     wire, e ele muda na Fase 3, não aqui.
#     `ausente` entra pela MESMA porta de `selado`: é VALOR de dado, não
#     identificador. A spec do subsistema 1 conta que "uma versão anterior
#     desta tabela dizia `ausente`" sobre o rótulo `estado` da métrica
#     (planning/spec-subsistema-1-indice-por-segmento.md:878), e o valor
#     `"ausente"` de `types.Presence.String` é contrato de wire que muda na
#     Fase 3, não aqui. O local `ausente` do schema virou `absent`, e o gate
#     nem o procura: token minúsculo sem maiúscula interna não entra no
#     índice de nomes velhos.
#     `Campos` entra pelo mesmo motivo de `campos`, só que na forma que abre
#     frase: "Campos fora de ordem (id 3 antes do id 1) violam a invariante"
#     (internal/testutil/fakestorage/fakestorage_test.go:315) fala dos campos
#     DO PAYLOAD, não do `Indexes.Campos` que virou `Fields`. O substantivo
#     PT-BR abre frase em vinte documentos e comentários; a citação
#     qualificada daquele campo não sobrou em lugar nenhum.
#   - CHAVE DE LOG cujo domínio é homônimo de identificador: a WARN
#     `janela.maior_que_retencao` (internal/server/history.go:133,
#     internal/server/history_test.go:265 e a tabela do README:723) é chave
#     de log estruturado, e chave de log é contrato que muda INTEIRO na
#     Fase 3. Sem a proteção o `janela` do binder a traduz pela metade e
#     sobra `window.maior_que_retencao`, que não é nem uma coisa nem outra.
